# YoungLife App

Мобильное приложение для YoungLife (iOS и Android). Сделано на React Native + Expo (Expo Router, TypeScript).

## Что уже есть (версия 0.1, демо)

- Вход и регистрация (имя, почта, пароль, дата рождения; от 14 лет)
- Роли: гость, лидер, старший лидер (выдаются администратором в базе)
- Список мероприятий и страница мероприятия (время, место, организатор, кнопка «Открыть на карте»)
- Создание мероприятий (только старший лидер)
- Чаты: общий чат у каждого мероприятия и личные сообщения (личные доступны, только если обоим собеседникам есть 15 лет); кнопка «Написать организатору»
- Инструменты лидера (личные, записи видит только сам лидер):
  - **Дерево**: одно имя на стволе, корней и веток сколько угодно, одно имя = один корень или одна ветка
  - **Список**: пять столбцов как в блокноте (Новые контакты, Клуб, Лидеры, Ученики, Спонсоры), имена перетаскиваются между столбцами
  - **Карта**: рисованная схема с клубом в центре и местами, за которые молится лидер (школа, двор, село, город), со статусом
  - у каждого имени и места есть заметка, которую можно скрыть
- Профиль с фото, описанием и кнопкой «Редактировать профиль»
- Настройки: язык, тема (авто, светлая, тёмная), уведомления
- Русский и английский интерфейс
- Минималистичный дизайн в цветах YoungLife (тёмно-синий и зелёный), светлая и тёмная темы, шрифт Onest

## База данных (Supabase)

Аккаунты, роли, профили, мероприятия и сообщения хранятся в Supabase.
Схема базы и правила защиты данных лежат в SQL-файлах (каждый запускается в SQL Editor, повторный запуск безопасен):

1. `supabase/schema.sql` — аккаунты, профили, мероприятия
2. `supabase/chat.sql` — чаты (запускать после первого файла)
3. `supabase/tools.sql` — Дерево, Список, Карта (запускать после первого файла)

- Роли «лидер» и «старший лидер» выдаёт только администратор (через SQL Editor).
- Дату рождения видит только сам пользователь, регистрация доступна с 14 лет.
- Правило 15+ для личных сообщений проверяется на сервере, обойти его из приложения нельзя.
- Старший лидер может удалять сообщения в общих чатах; свои сообщения может удалить каждый (долгое нажатие).
- Фото профиля пока хранится только на телефоне.

## Как запустить

1. Установи [Node.js](https://nodejs.org) (версия LTS) и приложение **Expo Go** на телефон.
2. В терминале, в папке проекта:

```bash
npm install
npx expo start
```

3. Отсканируй QR-код камерой телефона (iPhone) или из Expo Go (Android).

## Фото профиля
Запустите `supabase/photos.sql` в Supabase → SQL Editor (один раз). Фото сжимается до 512×512, хранится в облаке (папка `avatars`) и видно в чатах и в профиле.
