# YoungLife App

Мобильное приложение для YoungLife (iOS и Android). Сделано на React Native + Expo (Expo Router, TypeScript).

## Что уже есть (версия 0.1, демо)

- Вход и регистрация (имя, почта, пароль, дата рождения; от 14 лет)
- Роли: гость, лидер, старший лидер (переключаются в Профиле, только для теста)
- Список мероприятий и страница мероприятия (время, место, организатор, кнопка «Открыть на карте»)
- Создание мероприятий (только старший лидер)
- Вкладка «Инструменты» для лидеров: Дерево, Список, Карта (пока заготовки)
- Русский и английский интерфейс
- Нейтральный тёмный фон с зелёным акцентом YoungLife

> Сейчас аккаунты и мероприятия хранятся только в памяти телефона и пропадают при перезапуске. Сервер подключим на следующем этапе.

## Как запустить

1. Установи [Node.js](https://nodejs.org) (версия LTS) и приложение **Expo Go** на телефон.
2. В терминале, в папке проекта:

```bash
npm install
npx expo start
```

3. Отсканируй QR-код камерой телефона (iPhone) или из Expo Go (Android).

## План

1. Сервер (Supabase): настоящие аккаунты, роли, мероприятия
2. Чаты: общие чаты мероприятий и личные сообщения (детям до 15 лет только общие чаты)
3. Инструменты лидера: Дерево, Список, Карта
4. Пожертвования для поддержки приложения
5. Публикация в Google Play и App Store (после согласования с YoungLife)

## Структура

```
src/app/        экраны (Expo Router)
src/components/ общие элементы интерфейса
src/lib/        тема, переводы, роли, данные
```
